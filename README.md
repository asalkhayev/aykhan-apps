# Aykhan Applications 2027

Bachelor's application tracker. Static site, installable as an app (PWA).

## Put it online (GitHub Pages)
1. Create a new public repo on GitHub, for example `aykhan-apps`.
2. Upload everything in this folder to the repo root (`index.html`, `manifest.webmanifest`, `sw.js`, `icons/`). Keep the `icons` folder as a folder.
3. Repo Settings -> Pages -> Source: "Deploy from a branch" -> Branch `main`, folder `/ (root)` -> Save.
4. After a minute the site is at `https://<your-username>.github.io/aykhan-apps/`.

## Install as an app
- iPhone: open the link in Safari -> Share -> Add to Home Screen.
- Android: open in Chrome -> menu -> Install app.
- Desktop Chrome or Edge: install icon in the address bar.

## Notes
- Statuses, notes and tasks are saved in the browser on each device. They do not sync between devices.
- To update the site, replace `index.html` in the repo. Reopen the app to see the change.
